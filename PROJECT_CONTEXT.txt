1. نظرة عامة على المشروع (Project Overview)
--------------------------------------------------------------------------------
تطبيق ويب هجين متقدم (Mobile-First Web App) يهدف إلى تسريع وتسهيل عمليات تشخيص 
وصيانة الهواتف الذكية بنسبة 90% عبر محطة عمل متكاملة تجمع بين:
1. تشخيص ذكي بالذكاء الاصطناعي (أعطال الباور، الشحن، الشبكة، الشبلنة، وممانعات الكونكترات).
2. فحص فوري ومحاكاة دقيقة لسحب تيار الباور سبلاي (DC Power Supply Analyzer).
3. حاسبة فحص أمان الباينري لتفادي موت الأجهزة أثناء التفليش (Samsung SW REV Checker).
4. مولد سندات استلام وفواتير صيانة مهنية قابلة للطباعة مباشرة للعميل.

--------------------------------------------------------------------------------
2. المعمارية التقنية للمنظومة (Architecture)
--------------------------------------------------------------------------------
[Client: Browser / Acode SPA (index.html)]
                  │
                  ▼ (POST /api/diagnose)
[Vercel Serverless Function: api/diagnose.js]
                  │
                  ▼ (Authenticated HTTPS Request with GEMINI_API_KEY)
[Google Gemini API (gemini-3.5-flash-lite / gemini-3.5-flash)]

المزايا المعمارية:
- الأمان المطلق: عدم تضمين أي مفاتيح API داخل كود الواجهة أو GitHub.
- كسر الحظر الجغرافي: خوادم Vercel في أمريكا تنفذ الطلب نيابة عن العميل دون الحاجة لـ VPN.
- استقرار الخدمة: تدوير ذكي بين النماذج فائقة السرعة لتفادي ضغط السيرفرات (High Demand).

4. تفاصيل وتكوين الملفات البرمجية
--------------------------------------------------------------------------------

[ملف 1: vercel.json]
مسؤول عن توجيه المسار الرئيسي إلى index.html لمنع أخطاء 404:
{
  "version": 2,
  "routes": [
    { "src": "/api/(.*)", "dest": "/api/$1" },
    { "src": "/(.*)", "dest": "/index.html" }
  ]
}

[ملف 2: api/diagnose.js]
دالة Node.js Serverless تقرأ المفتاح السري process.env.GEMINI_API_KEY وتتصل بالنماذج:
- gemini-3.5-flash-lite
- gemini-3.1-flash-lite
- gemini-3.5-flash
- gemini-3.7-flash
- gemini-3.6-flash
وتلزم النموذج بالرد بصيغة RFC 8259 JSON حصراً باللغة العربية مع مصطلحات هندسية إنجليزية.

[ملف 3: index.html]
مبني بـ Vanilla JavaScript و CSS خالص بدون مكتبات ثقيلة لضمان السرعة القصوى.
يحتوي على 4 ألسنة عمل رئيسية:
1. تبويب الذكاء الاصطناعي (AI Diagnostic Engine).
2. تبويب محلل الباور سبلاي (DC Power Supply Current Analyzer).
3. تبويب حاسبة الباينري (Binary Safety Logic).
4. تبويب سند استلام وفاتورة العميل (Job Ticket & Print Engine).

6. سجل المشاكل التقنية والحلول الجذرية (Troubleshooting Ledger)
--------------------------------------------------------------------------------
1. مشكلة (High Demand 503 / 500):
   السبب: استدعاء نماذج قديمة متوقفة أو مزدحمة مجانياً.
   الحل: التحويل إلى جيل Flash-Lite الحديث (gemini-3.5-flash-lite).

2. مشكلة خطأ نحوي (Crash 500 في diagnose.js):
   السبب: تداخل نصوص عربية مقطوعة في السطر الأول أثناء اللصق في التيرمينال.
   الحل: تنظيف الكود واعتماد محرر Acode للتحرير والفحص بأمر (node -c).

3. مشكلة تعذر فتح الموقع (404 Not Found):
   السبب: Vercel يعامل المشروع كدوال بدون واجهة إذا لم يُحدد توجيه صريح.
   الحل: إضافة routes صريحة في vercel.json.

4. مشكلة حظر الموقع الجغرافي:
   السبب: Google API تحظر الاتصالات المباشرة من متصفحات بعض الدول.
   الحل: استدعاء الـ API حصراً عبر خادم Vercel Serverless الوسيط.

7. أوامر سريعة للإدارة والتحديث عبر Termux
--------------------------------------------------------------------------------
- رفع أي تعديلات جديدة:
  cd ~/evotech-ai && git add . && git commit -m "update" && git push origin main

- اختبار مسار السيرفر السحابي والتأكد من عمل الـ API:
  curl -i -X POST https://evo-tech-smart-phone-ai-5vgz.vercel.app/api/diagnose \
    -H "Content-Type: application/json" \
    -d '{"text":"SM-A125F test", "systemPrompt":"test"}'

- فحص صحة كود الجافاسكربت قبل الرفع:
  node -c api/diagnose.js
